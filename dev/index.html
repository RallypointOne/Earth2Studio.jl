Earth2Studio.jl

Overview

Earth2Studio.jl is a thin Julia wrapper around NVIDIA’s earth2studio Python package for AI-powered weather and climate forecasting. It uses PythonCall.jl to expose the full earth2studio Python API — data sources, prognostic and diagnostic models, perturbations, IO backends, run workflows, and verification statistics — as Python objects you can call from Julia.

The package itself is intentionally minimal: it imports earth2studio and its top-level submodules and holds them as Py references. Nothing is exported, because upstream names such as run and io would clash with Base. All functionality lives in the upstream Python package.

Quickstart

On first using Earth2Studio, CondaPkg.jl creates a Conda environment with Python (3.11–3.13), earth2studio[data] (version 0.18 or newer), and the conda-forge packages the data sources need. No manual pip step is required. Model extras are opt-in — add a CondaPkg.toml to your own project and CondaPkg merges it with the one shipped here:

[pip.deps.earth2studio]
extras = ["fcn", "pangu"]

Every reference is accessed through the module, e.g. Earth2Studio.data. DateTime and String convert to the Python types earth2studio expects, and Julia vectors are accepted wherever earth2studio iterates over a list. See the Tutorial for the full set of interop patterns and for running forecast models.

using Earth2Studio
using Dates
using CairoMakie
using PythonCall: pyconvert

ds = Earth2Studio.data.ARCO(verbose=false)
da = ds(DateTime(2023, 6, 15), "t2m")   # xarray.DataArray with dims (time, variable, lat, lon)

lon = pyconvert(Vector, da.lon.values)
lat = pyconvert(Vector, da.lat.values)
t2m = pyconvert(Array, da.values)[1, 1, :, :] .- 273.15   # lat × lon, °C

fig = Figure(size=(900, 450))
ax = Axis(fig[1, 1]; title="ERA5 2 m temperature, 2023-06-15 00:00 UTC", xlabel="Longitude", ylabel="Latitude")
hm = heatmap!(ax, lon, lat, permutedims(t2m))
Colorbar(fig[1, 2], hm; label="°C")
